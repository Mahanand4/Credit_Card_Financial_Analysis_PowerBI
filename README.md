# Credit Card Financial Analysis Power BI

Credit Card Financial Analysis Dashboard using Power BI and DAX.

## Project Overview

This project focuses on analysing credit card customer and transaction data using Power BI. The dashboard provides insights into revenue, transactions, customer demographics, spending behaviour, and other key financial metrics.

## Tools & Technologies

- Power BI
- DAX
- Excel / CSV
- Data Cleaning
- Data Visualization

## Key Analysis

- Revenue and transaction analysis
- Customer segmentation
- Spending behaviour analysis
- Card usage analysis
- Customer demographic analysis
- KPI and trend analysis

## Dashboard

The Power BI dashboard presents interactive visualizations and KPIs to support data-driven business decisions.

## Project Outcome

The project demonstrates the use of Power BI and DAX to transform credit card data into meaningful business insights and an interactive dashboard.

This repository contains the project files and documentation for the Credit Card Financial Analysis project.
